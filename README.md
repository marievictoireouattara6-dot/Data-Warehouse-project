# Data-Warehouse-project
Project Description

The idea for this project came from my curiosity about how databases are used in different areas of everyday life. At first, I was thinking about applications and platforms that we use regularly, such as Yango and YouTube, and how databases are essential to make these services work. I then started wondering about other areas where databases play an important role, especially in the travel and aviation industry.

When we want to travel by plane, we usually interact with a website or an application where we can search for flights, choose a destination, make a reservation, select a seat, and complete a payment. However, behind this simple process, there is a complex system that needs to manage and connect a large amount of information. This made me interested in understanding how such a system could be organized through a relational database.

For this project, I decided to design a database for an airline booking system, inspired by the general functioning of airlines such as Air France. The main objective is to create a database that could support a website where users can search for flights and book their trips.

To represent the different aspects of an airline booking system, I selected several entities that are essential to the project: Passenger, Flight, Airport, Aircraft, Reservation, Crew, Flight_Crew, and Payment. These entities represent the main components involved in the process, from the passenger and the flight itself to the airports, aircraft, crew members, reservations, and payments.

Through this project, I want to understand how these different elements can be connected within a database and how a relational database can be used to support a real-world service such as an airline booking platform. The project will therefore focus not only on creating the database structure, but also on understanding how data can be organized and related to reproduce a realistic airline reservation system.
